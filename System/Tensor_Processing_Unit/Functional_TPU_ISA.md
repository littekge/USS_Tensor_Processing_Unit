# Functional TPU Instruction Set Architecture (ISA)
> **Purpose:** This document contains the *Functional TPU* instruction set architecture specification. 

## Instruction Format
This section describes the general format of *Functional TPU* instructions. In the *Functional TPU* ISA, there are two core instruction formats (ARITH, SHAPE) which both have a fixed length of 128 bits. Instructions are described with the most significant bit (127) on the left side of the instruction, and the least significant bit (0) on the right side.
