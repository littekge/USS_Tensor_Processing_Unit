Functional TPU · v0.3 quantization

Deriving the requant scales, and decomposing M

Two derivations behind per-tensor requantization: how the scales S_w, S_in, S_out are measured for each layer, and how the combined scale M becomes the integer pair (M0, n) the hardware evaluates.

Question 01

Computing S_w, S_in, and S_out per layer

The common definition

All three are the same kind of object: a scale S mapping a real tensor onto signed int8 in the symmetric range [−127,127].

S= rmaxqmax , qmax=127
r_max
the calibration magnitude — the largest absolute real value the tensor needs to represent.
q_max
127, the largest int8 magnitude. Using 127 (not 128) keeps the grid symmetric: −127…+127.

The quantize / dequantize pair this induces, for a real value r:

q=round ( clip( rS ,−127,127 ) ) , r^=S⋅q≈r
q
the stored int8 value.
r̂
the reconstructed real value (r^).

The only thing distinguishing the three scales is which tensor's r_max you measure.

The calibration magnitude

Let D be a calibration set: a representative batch of network inputs (the 1000–2000 samples used in the forward-pass analysis). For any tensor A:

rmax(A)= maxd∈D maxelem |A(d)|

The three cases

S_w — weight scale (static). Weights are fixed at compile time, so no data is needed — measured straight from the trained tensor Wℓ of layer ℓ:

Sw= max|Wℓ| 127

This is what Process_Weights.py should compute per layer — instead it hardcodes Sw=1/128, which is why small-weight layers waste the grid and large-weight layers (Tiny_NN's 1.185) clamp.

S_in — input-activation scale (dynamic). The activations feeding layer ℓ depend on the data, so they must be observed:

Sℓin= rmax(Xℓin) 127

This is the in.absmax the forward-pass hooks measured; it requires running the model.

S_out — output-activation scale (dynamic). Same, for the layer's pre-activation output Xℓout — the accumulator result, before ReLU/pool, because that is what the systolic array produces and what gets requantized:

Sℓout= rmax(Xℓout) 127

Two structural facts

Chaining. An activation tensor is one layer's output and the next layer's input, so Sℓout=Sℓ+1in. You compute one scale per activation tensor, not two.

Percentile variant (a tuning knob). Instead of a hard maximum, use a high quantile to reject outliers:

rmax(A)= quantile(|A|,0.999)

Strict absmax never clips but is coarser; the percentile clips the top 0.1% of values in exchange for finer resolution.

Question 02

Decomposing M into M0 and n

The combined scale M=(Sin⋅Sw)/Sout is a positive real, almost always ≪1 (LeNet conv1: M = 0.0013730). We want an integer-only form:

M≈ M0⋅ 2−n
M0
a positive integer, the quantized multiplier (the mantissa), held to a fixed bit width B (we use B=31).
n
a non-negative integer, the shift (the exponent).
B
the multiplier bit width. Choosing n so that M0∈[2B−1,2B) uses every significant bit.

The algorithm (binary floating-point, done offline)

Step 1 — normalize the mantissa into [0.5,1):

e= ⌊log2M⌋ +1 , m=M⋅ 2−e
e
the binary exponent, chosen so the real mantissa m lands in [0.5,1).
m
the normalized real mantissa.
Worked example · LeNet conv1 log2(0.0013730)=−9.51, so e = −10 + 1 = −9 and m = 0.0013730 · 2⁹ = 0.7030 ∈ [0.5, 1). ✓

Step 2 — quantize the mantissa to B bits:

M0= round(m⋅2B)

Since m∈[0.5,1), this lands M0∈[2B−1,2B) as required.

Worked example · LeNet conv1 M0 = round(0.7030 · 2³¹) = 1 509 670 765 ✓

Step 3 — fold the exponent into the shift. From M=m⋅2e and m=M0⋅2−B:

M= M0⋅ 2−B⋅ 2e = M0⋅ 2−(B−e) ⟹ n=B−e
Worked example · LeNet conv1 n = 31 − (−9) = 40 — matching the script's M0 = 1509670765, n = 40. ✓

What the hardware evaluates

With acc the 32-bit signed accumulator, requantization is one multiply, one rounding add, one shift, one clamp:

// acc·M0 is a 32×31 → ~63-bit product (needs a 64-bit intermediate)
q_out = clip( ( acc * M0 + 2^(n-1) ) >> n , -128, 127 )
        └ round-half-up ┘   └ shift ┘   └ int8 saturate ┘

Precision — why it read "0.0 ppm"

M0=round(m⋅2B) has a mantissa rounding error of at most half an LSB, so the relative error of M^=M0⋅2−n versus M is:

|M^−M| M ≤ 2−B⋅12 m ≤ 2−(B−1) ≈ 2−30 ≈ 10−9

Sub-ppb — effectively exact, which is why every layer reproduced to 0.0 ppm.

Edge case If a layer had M≥1 (amplifying), then e≥1 and n=B−e<B; the same formulas hold, the shift is just smaller. Our networks all have M≪1, so n is large (38–42).
